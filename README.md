# Шумология — сборка для деплоя

Статический сайт. Сборка не требуется: содержимое папки заливается на хостинг
как есть, точка входа — `index.html`.

## Что внутри

```
index.html
css/    base.css, components.css, sections.css, mobile.css
js/     main.js, anim.js, vendor/gsap.min.js, vendor/ScrollTrigger.min.js
fonts/  (пусто — см. ниже)
*.jpg / *.png / *.svg / *.mp4 — медиа
```

Внешних зависимостей на этапе сборки нет. GSAP лежит локально в `js/vendor/`.

## Перед публикацией

### 1. Шрифт Wadik — обязательно

Файлы `fonts/Wadik.woff2` и `fonts/Wadik.woff` **отсутствуют**: их не было
в исходных материалах. Правило `@font-face` уже прописано в `css/base.css`,
достаточно положить файлы в `fonts/` — подхватятся автоматически.

Пока их нет, все заголовки рендерятся запасным Onest 700. Вёрстка не ломается,
но начертание отличается от макета.

### 2. Вес видео на первом экране

`Видео на главную (секунд 30).mp4` весит **48 МБ** — это 85% всей сборки.
Для продакшена его нужно пережать, ориентир — 3–5 МБ:

```bash
ffmpeg -i "Видео на главную (секунд 30).mp4" \
  -vf "scale=1280:-2" -c:v libx264 -crf 28 -preset slow \
  -an -movflags +faststart hero.mp4
```

`-an` убирает звуковую дорожку (видео и так проигрывается без звука),
`+faststart` позволяет начать воспроизведение до полной загрузки.
После перекодирования замените имя файла в `index.html`.

Остальные изображения имеет смысл перегнать в WebP — суммарно даст ещё ~40%.

### 3. Шрифт Onest подключается с Google Fonts

`css/base.css` начинается с `@import` к `fonts.googleapis.com`. Если сайт
должен работать без обращений к внешним доменам, скачайте Onest
(веса 300/400/500/700, кириллица) в `fonts/` и замените `@import`
на локальные `@font-face`.

## Не вошло в сборку

Эти файлы остались в рабочей папке и на сайте не нужны:

- `contour-picker.html` — инструмент для снятия контуров зон кузова.
  Пригодится, когда будете добавлять новые зоны (пороги, крылья, крыша).
- `hover-zones.html` — ранний прототип подсветки.
- `Контур двери.svg`, `Капот контур.svg`, `Багажник конкур.svg` — исходные
  векторные контуры. В сборке они уже вшиты в `index.html` как `<clipPath>`.
- PDF-макеты, `Пример анимации.mov`, неиспользуемые иконки и старые фото.

## Что осталось незавершённым

- **Расчёт в калькуляторе статичный.** Цены зон и составы материалов заданы
  в разметке, суммы пересчитываются по выбранным зонам. Для реальных данных
  нужен бэкенд.
- **Справочник авто** — в начале `js/main.js`, объект `CARS`. Заменяется
  выгрузкой без правки разметки.
- **Цены товаров** в каталоге берутся из атрибута `data-price` в разметке.
- **Контуры зон** есть для дверей, капота и багажника. Пороги, крылья и крыша
  требуют новых контуров и, для части из них, дополнительных ракурсов съёмки.
- **Формы ничего не отправляют** — нужен обработчик на бэкенде.
